# UnityHybridVPN (`PROJ-002-hybrid-vpn`)

عميل VPN هجين مستقل ومجاني لنظام Windows 10/11 يدعم ملفات `WireGuard (.conf)` و`OpenVPN (.ovpn)` مع فحص أمان صارم، قائمة خوادم `VPNGate` المجتمعية متعددة الدول، ومساعد تنصيب خادم شخصي بضغطة واحدة.

- **التشغيل:** `release\UnityHybridVPN-Portable\UnityHybridVPN.exe`
- **الاختبارات:** `dotnet run --project tests\UnityHybridVPN.Tests\UnityHybridVPN.Tests.csproj -c Release` (`5/5 PASS`).
- **مسار الإعدادات المستقل:** `%LocalAppData%\UnityHybridVPN\`
